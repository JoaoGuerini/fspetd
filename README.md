# PetConecta — PM Canvas

Project Model Canvas do projeto **PetConecta**, plataforma que conecta tutores a
cuidadores de pets em Vilhena.

Disciplina: Fábrica de Software I · IFRO Campus Vilhena · 2026/2

## Sobre

Página estática única ([index.html](index.html)), sem build e sem dependências.
Para ver localmente, é só abrir o arquivo no navegador.

Recursos da página:

- **Modo slide 16:9** — clique em "Project Model Canvas" no rodapé (Esc para sair).
- **Zoom de seção** — clique no título de qualquer bloco para ampliá-lo.
- **Impressão** — layout A4 paisagem já configurado no `@media print`.

Itens destacados em rosa são pontos ainda pendentes de decisão.
